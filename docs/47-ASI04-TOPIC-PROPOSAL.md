# ASI04 — Topic Proposal (T111 ka pehla kadam)

**Status: faisla baki hai.** Ye page kahani *ghad* nahi rahi — teen asal, jaanchi hui dishaayein rakh rahi hai taaki ek chunna aasan ho. Jo chunoge, usi par Director's Note (T113) banega, ASI05 wale hi usool (Gate 0–5, document pehle) ke saath.

ASI05 ne sikhaya: *bahar ki report me chhupa hukm → secret read → token bahar.* ASI04 usse **alag galti** honi chahiye, warna series ek hi seekh do baar bolegi.

## Option A — “The Helpful Summary” (sifaarish)

- **Ghatna:** Ractor ko ek lambi shared report *summarize* karne ko milti hai. Report ke andar chhupi ek line summary me ek **jhootha daava** ghusa deti hai: “Sab tests pass ho gaye.” Ractor summary aage bhej deta hai. Phir wahi kaam ek jaanch-wale tareeqe se: daave ko source se milana, bina saboot wala daava summary se bahar.
- **Seekh:** Summary = source ki zimmedari bhi le leti hai. Har daave ko uski jad (source line) se jodo.
- **ASI05 se fark:** Yahan raaz nahi nikalta — **jhooth aage badhta hai.** Nuksaan “leak” ka nahi, “bina jaanch ke dohraya gaya jhooth” hai.
- **Visual taakat:** Document → summary card me ek line ka laal hona; phir wahi line ka source se takraana. Chomsky nahi, saaf aur dikhne wala.

## Option B — “The Calendar Trap”

- **Ghatna:** Ek calendar invite ke notes me chhupa hukm: meeting ki andar ki baatein kisi aur ko bhej do. Pehle flow me Ractor karne jaata hai; Replay me invite ko sirf *data* maankar kaam hota hai.
- **Seekh:** Jo khud tumhare calendar/mail me pahunch jaye, wo tumhara hukm nahi ban jaata.
- **Risk:** ASI05 se meel zyada (chhupa hukm phir se) — seekh nayi hai par chaal purani lagegi.

## Option C — “The Copy-Paste Fix”

- **Ghatna:** User kisi forum se “fix” copy karke agent ko deta hai; beech me ek chhupi harkat (file delete/account band jaisi) chhupi hai. Replay me agent pehle *dikhata* hai ki paste ke andar kya-kya hai, phir chalata hai.
- **Seekh:** Paste ki gayi cheez bhi bahar ki cheez hai — pehle kholkar dekho, phir chalao.
- **Visual taakat:** Paste box ke andar chhupi line ka ubharna; “chalane se pehle dikhao” ka bandobast.

## Meri sifaarish

**Option A.** Kaaran: (1) seekh bilkul nayi hai — jhooth ka aage badhna, raaz ka nikalna nahi; (2) ASI05 ke “test passed kabhi nahi likhte” wale apne sach-parak usool se seedha judti hai; (3) board par saaf dikhegi. Tum “A / B / C” me se ek shabd bologe, main Director's Note wahi se shuru karunga.

*Note: koi bhi option “asal company par aarop” nahi hai — ASI05 ki tarah kalpanik par satya-parak (asli pattern, banaya hua kissa) rahegi.*
