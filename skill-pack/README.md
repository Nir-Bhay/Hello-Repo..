# Skill Pack — Ractor Video Production (user-uploaded)

User ke diye hue production skills ka complete set, **bina ek bhi file miss kiye** save kiya gaya hai (24 Oct 2026). Saari files original bytes me hain; sirf folders is tarah rakhe hain ki SKILL.md ke `references/...` links kaam karein.

## Structure

```
skill-pack/
  README.md                     ← ye file (index)
  REVIEW.md                     ← agent ka pura review (strengths, gaps, adopt-list)
  MANIFEST.md                   ← har file ka size + SHA-256 (byte-identical proof)
  ractor-video-production/
    SKILL.md                    ← main skill entry
    references/                 ← 9 reference docs (visual, audio, brand, gates…)
  ractor-motion-direction/
    references/                 ← style-system + review-gates
    (SKILL.md is pack me NAHI aaya — REVIEW.md me flag hai)
  agents/                       ← 3 reviewer agents (geometry / portrait / story)
  episodes/
    asi05/DIRECTOR-NOTE.md      ← ASI05 episode ki poori director's note
```

## Kaise use hoga

- Jab **Ractor episode** (OWASP ASI series) pe kaam hoga, pehle `ractor-video-production/SKILL.md` padha jayega, phir kaam ke hisaab se references.
- Reviewer agents (`agents/`) rough-cut stages par challenge karne ke liye hain — ye source edit nahi karte, findings dete hain.
- Ye pack Hello Motion Studio ki apni identity se alag hai; hamare apne videos ke liye `docs/04-MOTION-DESIGN-BIBLE.md` hi chalega. Dono ke beech kya adopt karna hai, `REVIEW.md` ke aakhir me list hai.
